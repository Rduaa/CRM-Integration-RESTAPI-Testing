# CRM Integration REST API Testing

## Project Overview
This repository contains QA artifacts for testing REST API integrations of a CRM system.
The project focuses on validating data exchange between CRM, external services, and internal modules.

## Testing Scope
- CRM REST API integration testing
- Data validation between systems
- Error handling and negative scenarios
- Regression and smoke testing

## Tools Used
- Postman
- SQL
- Markdown
